# 🧬 KREIT · Официальный веб-портал GENY NETWORK

Интерактивный киберпанк веб-портал для Discord-бота **GENN BOT / GENY** в ультра-тёмном минималистичном стиле OpenCode Gateway.  
Отображает пользователей, их аватары, актуальные **GEN-номера**, цвета, балансы, рейтинги лидеров, фактор доверия и предметы в реальном времени.

---

## ⚡ Развёртывание на Vercel (1 клик)

Сайт полностью оптимизирован и готов к деплою на **Vercel** (`vercel.app`):

1. Зайдите на [vercel.com](https://vercel.com/) и нажмите **Add New Project**.
2. Выберите репозиторий: **`MAG1STER343/KREIT`**.
3. Нажмите **Deploy** (все настройки и `vercel.json` уже вшиты, сборка происходит мгновенно).
4. **Готово!** Ваш сайт доступен всему миру по постоянному адресу `https://kreit.vercel.app`.

### 🔄 Как связать Vercel с работающим ботом:
- В настройках проекта на Vercel (**Settings** ➔ **Environment Variables**) добавьте переменную:
  - `BOT_API_URL` = `https://ваш-туннель.ngrok-free.app/api/sync` (или публичный IP / домен вашего сервера бота).
- Если бот выключен или переменная не задана, сайт автоматически работает в **автономном режиме** из встроенного снимка базы данных (`data/cache_database.json`).

## ✨ Основные возможности

1. **🌌 Анимированный тёмно-голубо-синий фон с матовыми частицами:**
   - Высокопроизводительный HTML5 Canvas фон на глубоком чёрном фоне `#000000` с сапфировыми световыми ореолами.
   - **Многослойный эффект матового стекла (Frosted Glass / Bokeh):**
     - Дальний план: крупные мягкие размытые круги света (размытие 24px).
     - Средний план: летающие светящиеся частицы с нежным матовым ореолом.
     - Передний план: мерцающие парящие белые светлячки.
   - Интерактивный лёгкий параллакс и подсветка при движении курсора мыши.

2. **🖼️ Автоматическое отображение и обновление аватарок:**
   - Аватарки пользователей подгружаются напрямую через Discord CDN.
   - При смене аватарки пользователем в Discord бот фиксирует событие и мгновенно сохраняет актуальную ссылку.

3. **⚡ Синхронизация данных с ботом раз в 5 секунд:**
   - **При включенном боте:** опрашивает API бота каждые **5 секунд**, удаляет старую базу и загружает свежую активную в реальном времени.
   - **При выключенном боте:** сайт мгновенно переходит в **автономный режим**, сохраняя последний снимок базы данных на сервере (`data/cache_database.json`). Данные не теряются.
   - **При повторном включении бота:** автономный кэш автоматически перезаписывается свежими актуальными данными бота.

4. **🏆 Динамический Топ лидеров (Leaderboard):**
   - Переключение рейтингов:
     - 🪙 **По G.COIN** (самые богатые игроки)
     - ⭐ **По STARS** (премиум-магнаты)
     - 🛡️ **По Фактору доверия** (Trust factor 0–120 с щитами)
     - 🏆 **По Уровню** (LVL и опыт XP)
     - 🎤 **По Войс-онлайну** (проведённое время в голосовых каналах)
   - Подиум Топ-3 с коронами (🥇, 🥈, 🥉) и неоновым свечением цветов GEN.
   - Полная техническая таблица рангов для остальных участников.

5. **👥 Каталог пользователей & Поиск:**
   - Мгновенный живой поиск по никнейму или номеру GEN (например: `0.159`).
   - Фильтрация по цветам GEN (красный, синий, бирюзовый, platinum, gold и др.).
   - Сортировка по любой валюте или активности.
   - Карточки с аватарками, значками щита фактора доверия (🔴 1–30, 🟠 31–49, 🟢 50+), балансами и полкой надетых подарков.

6. **👤 Интерактивный профиль пользователя (Modal):**
   - Нажатие на любую карточку открывает полноценный профиль в окне с анимацией.
   - Подробная статистика: голосовые часы, количество сообщений, фактор доверия со шкалой прогресса, все надетые подарки.

7. **🛒 Витрина биржи BOURSE:**
   - Просмотр активных лотов GEN-номеров и предметов, выставленных игроками на бирже.

## 💻 Локальный запуск (без Vercel)

### 1. Установка зависимостей:
```bash
pip install -r requirements.txt
```

### 2. Запуск сервера:
На Windows:
Дважды кликните по файлу **`start_site.bat`**  
Или через терминал:
```bash
python server.py
```

На Linux / macOS:
```bash
./start_site.sh
```

После запуска сайт доступен в браузере по адресу:  
👉 **`http://localhost:3000`**
