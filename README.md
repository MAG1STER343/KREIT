# 🧬 KREIT · Официальный веб-портал GENY NETWORK

Интерактивный киберпанк веб-портал для Discord-бота **GENN BOT / GENY**.  
Отображает всех пользователей, их уникальные **GEN-номера**, цвета, балансы, уровни, рейтинги лидеров, фактор доверия и предметы в реальном времени.

---

## ✨ Основные возможности

1. **🌌 Анимированный тёмно-голубо-синий фон с матовыми частицами:**
   - Высокопроизводительный HTML5 Canvas фон, повторяющий визуальный стиль карточек профиля бота.
   - Шелковистые рассеянные световые зоны сапфировых и ночных индиго-тонов.
   - Плавно парящие светящиеся белые частицы с многослойным боке-эффектом матового стекла (Frosted Glass).
   - Интерактивная реакция на курсор мыши.

2. **⚡ Синхронизация с ботом раз в 5 секунд:**
   - **При включенном боте:** сайт опрашивает API бота каждые **5 секунд**, удаляет старую базу и загружает свежую активную в реальном времени.
   - **При выключенном боте:** сайт мгновенно переходит в **автономный режим**, сохраняя последний снимок базы данных на сервере (`data/cache_database.json`). Данные не теряются.
   - **При повторном включении бота:** автономный кэш автоматически перезаписывается свежими актуальными данными бота.

3. **🏆 Динамический Топ лидеров (Leaderboard):**
   - Переключение рейтингов:
     - 🪙 **По G.COIN** (самые богатые игроки)
     - ⭐ **По STARS** (премиум-магнаты)
     - 🛡️ **По Фактору доверия** (Trust factor 0–120 с цветовыми щитами)
     - 🏆 **По Уровню** (LVL и опыт XP)
     - 🎤 **По Войс-онлайну** (проведённое время в голосовых каналах)
   - Подиум Топ-3 с коронами (🥇, 🥈, 🥉) и неоновым свечением цветов GEN.
   - Полная стеклянная таблица рангов для всех остальных участников.

4. **👥 Каталог пользователей & Поиск:**
   - Мгновенный живой поиск по никнейму или номеру GEN (например: `0.159`).
   - Фильтрация по цветам GEN (красный, синий, бирюзовый, platinum, gold и др.).
   - Сортировка по любой валюте или активности.
   - Карточки с аватарками, значками щита фактора доверия (🔴 1–30, 🟠 31–49, 🟢 50+), балансами и полкой надетых подарков.

5. **👤 Интерактивный профиль пользователя (Modal):**
   - Нажатие на любую карточку открывает полноценный профиль в стеклянном окне с анимацией.
   - Подробная статистика: голосовые часы, количество сообщений, фактор доверия со шкалой прогресса, все надетые подарки.

6. **🛒 Витрина биржи BOURSE:**
   - Просмотр активных лотов GEN-номеров и предметов, выставленных игроками на бирже.

## 🚀 Быстрый запуск

### 1. Установка зависимостей:
```bash
pip install -r requirements.txt
```

### 2. Запуск сервера:
На Windows:
Дважды кликните по файлу **`start_site.bat`**  
Или через терминал:
```bash
python server.py
```

На Linux / macOS:
```bash
./start_site.sh
```

После запуска сайт доступен в браузере по адресу:  
👉 **`http://localhost:3000`**

---

## 🔌 Как работает связь с ботом

1. Бот при запуске поднимает локальный API-сервер на порту `5055` (`web_sync_server.py`).
2. Веб-портал (`server.py`) автоматически опрашивает бота каждые 5 секунд по адресу `http://127.0.0.1:5055/api/sync`.
3. В шапке сайта отображается статус:
   - 🟢 **БОТ ОНЛАЙН (Синхронизация раз в 5 сек)**
   - 🟠 **АВТОНОМНЫЙ РЕЖИМ (Сохранённая база)**
